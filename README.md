# Mohamed Sami – Engineering & Digital Innovation Portfolio

Static, self-contained portfolio site (HTML, CSS, JavaScript; no build step, no backend).

- `index.html` – the whole site
- `assets/img` – screenshots (WebP, with `_t` thumbnails)
- `assets/video` – demo videos (MP4) and posters
- `assets/docs` – downloadable CV (PDF)
- `assets/fonts`, `assets/logos` – self-hosted font and company logos

## Public version
Contract values are rounded and exact monetary figures and contract numbers are blurred in screenshots and videos.
The unredacted offline version is kept separately and is not published.

## Updating
Edit or replace files, then upload them to this repository (Add file → Upload files). GitHub Pages republishes in about a minute.
